## 3. Standard Operating Procedures (SOPs)

### SOP-01: Adding a New Video to Tha Visuals
1. Place video thumbnail in `public/images/` and local MP4 (if hosted) in `public/videos/`.
2. Add video object to `videoList` in `app/tha-visuals/page.tsx`.
3. Register the video in `BASE_VIDEO_STATS` in `lib/db.ts` with strict 0 counts:
   ```typescript
   "new-video-id": {
     videoId: "new-video-id",
     videoTitle: "NEW TITLE",
     category: "CATEGORY",
     totalPlays: 0,
     subscriberPlays: 0,
     nonSubscriberPlays: 0,
     lastPlayedAt: null,
   }
   ```
4. Run `npm run build` to verify route integrity.

### SOP-02: Adding a New PDF Blueprint to Digital Workflow
1. Place PDF asset in `public/downloads/`.
2. Add asset definition to `BASE_PDF_STATS` in `lib/db.ts` with `totalDownloads: 0`, `lastDownloadedAt: null`.
3. Add UI card in `app/digital-workflow/page.tsx` referencing the new blueprint.
4. Verify download trigger invokes `/api/download/track` before initiating file download.

### SOP-03: Updating Admin Live Telemetry Counters
1. Ensure any new metric is added to `/api/admin/data/route.ts` under `metrics`.
2. Ensure new metrics are pure counts with no synthetic minimums.
3. Update `AdminTelemetryData` interface in `app/admin/page.tsx`.
4. Handle null/zero states safely (e.g. `lastPlayedAt ? formatTime(stat.lastPlayedAt) : "No plays yet"`).

### SOP-04: Building and Deploying Changes
1. Run local build check:
   ```bash
   npm run build
   ```
2. Check git status to ensure only intended files are modified:
   ```bash
   git status
   ```
3. Stage, commit with clear message, and push:
   ```bash
   git add -A
   git commit -m "feat: <feature description>"
   git push origin main
   ```
4. Netlify automatically triggers build via webhook on `main`.

## 4. Troubleshooting & Diagnostic Memory

| Issue | Root Cause | Solution |
| :--- | :--- | :--- |
| **Active Sessions shows wrong count** | Mock users in `data/network_db.json` or artificial floor in route | Verify `activeRecently: activeRecentlyCount` in `/api/admin/data/route.ts` and ensure only authentic users are in `data/network_db.json`. |
| **Get U Some Game button visible on Home** | Global rendering in `components/AuthGate.tsx` | Button must only exist in `app/tha-visuals/page.tsx` guarded by `isSubscribed`. |
| **Video play counters not incrementing** | Video player not dispatching `/api/video/play` | Verify `recordPlayEvent` is called on video select or play in `app/tha-visuals/page.tsx`. |
| **Netlify deployment fails on video size** | Large MP4 files exceeding standard Git limits | Ensure Git LFS is enabled in `netlify.toml` (`GIT_LFS_ENABLED = "true"`). |
